# Piedra, Papel o Tijera — Videojuego Interactivo

Aplicación web interactiva que recrea el clásico juego de Piedra, Papel o Tijera. Permite al usuario competir contra la computadora mediante una interfaz dinámica, con validación instantánea de jugadas, seguimiento de puntajes en tiempo real y retroalimentación visual en cada ronda.

## Características principales
* **Mecánica de juego en tiempo real:** Elección aleatoria automatizada para la computadora y evaluación inmediata del ganador por ronda.
* **Marcador dinámico:** Conteo en vivo de victorias, derrotas y empates durante la partida.
* **Interfaz intuitiva y responsiva:** Controles visuales claros adaptados tanto para pantallas de escritorio como dispositivos móviles.

## Lenguajes y herramientas utilizadas
* **Desarrollo Web:** HTML5, CSS3, JavaScript
* **Control de versiones:** Git y GitHub Desktop
